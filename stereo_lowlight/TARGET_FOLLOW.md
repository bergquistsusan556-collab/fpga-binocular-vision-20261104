# 指定靶标跟随测距

2026-11-03，用户反馈当前距离已准确，要求继续实现跟随。本次保留已接受的`front_fit_20261103`测距模型，开发独立`target_follow_20261103`。目标是之前PDF第1页的ArUco DICT_4X4_50 ID7及其辅助随机纹理带，属于屏幕目标框与测距区域跟随，不涉及机械云台。

## 使用

跟随版本默认进入模式7：底图仍是双目增强视频。绿色矩形表示识别到7号标记；白色矩形表示真正用于双目测距的辅助纹理区域。绿色状态点表示识别有效，黄色表示寻找目标；距离无效或目标丢失时显示横线。

将完整标记、四周白边及辅助纹理带同时放进双目视野，无需先对准画面中央，也无需手动截取模板。先让靶标正对镜头并静止，确认绿色框和有效距离；然后缓慢左右、上下及前后移动。移出画面后应撤销目标框和有效距离，重新进入后自动识别。同一画面存在两个7号标记时拒绝输出，避免在两个相同身份间跳转。

KEY0仍循环切换八种模式，默认7之后依次0、1、2、3、4、5、6、7。模式0为原始双目，1为增强，2为全场视差，3为彩条，4为二值化，5为边缘，6为帧差运动检测，7改为本次指定标记跟随。模式0至2仍使用原中心区域测距。KEY1/2/3沿用原距离比例及视差方向操作，现场验证时避免误触。

## 实现

- 识别分支使用增强前的原始亮度，按完整帧亮度范围更新二值阈值；显示仍使用原增强结果。防止亮度修复把标记黑块提亮后破坏检测。
- 右目每2像素采样，形成200×240的同一LCD帧二值快照。后台扫描黑色边框候选，沿两侧边框上下查找并归一化顶边、底边，估计宽高，校验6×6标记及白色邻域，支持四个90度方向。不同大小不依赖原模板的固定64×64框或16像素搜索网格。增加小角度斜边图案测试，减少非等比例400×480视图中顶边候选的抖动。
- 仅接受ID7的编码，允许一个采样单元错误。构建测试从OpenCV字典独立生成图案，核对ID7与其他49个ID所有旋转的最小有效位差至少4；测试最近的44/45号标记仍拒绝。不是完整OpenCV ArUco库的FPGA移植，不具备任意透视四边形拟合。
- 根据PDF几何定位辅助纹理带：正向标记的纹理中心位于顶边下方标记高度的19/16，其他方向相应旋转。测距窗口随标记位置和大小变化，并检查是否仍在画面内；取纹理带中间约75%的宽、高，长半轴最多40像素，短半轴最多20像素。
- 保留原Census代价、纹理/唯一性门槛、ROI集中度和样本数检查，保留`A_Q8=561884、B_Q8=2677`及手动比例。增强、全场视差和其他图像功能不改。
- 仅模式7且原行补偿已启用时，局部搜索基础行补偿的±4行（裁剪至0～31）。每个候选先等待两帧清除旧统计，再累计两帧合格测量的主峰数量，选取最高者；测量仍须通过原质量门槛且属于当前靶标纹理。选择后再等待帧数据稳定才允许显示距离，连续8帧合格靶标下无有效测量则重搜。模式0～6直接使用原控制值。该功能是有限范围平移补偿，不是完整镜头/极线校正，也没有使用参考距离选择补偿值。
- ROI每帧锁存边界，将完成统计的区域位置随距离一起保存。跟随模式要求该测量窗口仍全部落在当前目标的完整纹理带内，允许不超出纹理带的定位微抖动；超出则在新区域完成测量之前撤销有效位。固定中心模式仍要求精确位置相等。检测丢失时清空距离，缺帧、模式退出及超时也清除过期目标。
- 定位和距离存在帧处理延迟，视频显示不等待后台搜索。明显倾斜、遮挡、过小或运动模糊可能导致拒绝；跨姿态和动态厘米误差仍需实物验证。
