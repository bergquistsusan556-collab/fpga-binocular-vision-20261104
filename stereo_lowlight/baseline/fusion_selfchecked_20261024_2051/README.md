## 当前处理链

两路 OV5640 各输出 400×480 RGB565，经异步 FIFO 和 DDR3，按每行左 400 像素、右 400 像素读出。LCD 时钟固定 25 MHz，经 BUFG 分配，1056×525 总时序对应约 45.09 Hz。诊断实测摄像头 PCLK 约 48 MHz、每路约 26.67 帧/秒；显示会重复最近一帧，不能把 LCD 刷新率称为摄像头采集帧率。

增强：RGB565 → YCrCb 亮度/色度分离；亮度的因果 3×3 窗口采用带范围门限的加权照明估计；倒数与 gamma 增益查表，最大增益 4；结合上一帧双目共享的 64 桶亮度 CDF，限制混合不降低局部增强亮度；保留色度并饱和重建 RGB。它是适配 A7 资源的定点 LIME 思路改进版，不是原浮点 LIME 的逐位等效移植，也没有对三个 RGB 通道独立均衡。

匹配：原始亮度 3×3 Census，1～63 像素水平搜索，三列代价聚合，流水化最优/次优筛选；纹理不足、边界、代价过大或不唯一时输出无效。适用于普通有纹理物体，不依赖红色检测。没有实现 SGM、左右一致性校验、完整镜头畸变矫正或极线重映射。没有经过双目标定前，实际匹配质量和精度待测。

视差图覆盖整个右目视场，置信有效位单独保存。每个显示帧完成一次双缓冲切换；存储分辨率 200×240，放大到整块 800×480 LCD。黑色表示无效，蓝至红表示视差由小到大；这是视差伪彩图，不能称为已标定的逐像素公制深度图。右目中心 41×41 区域通过主峰及相邻视差桶加权均值估计距离，不用单个像素代表整个物体。

## 按键

| 按键 | 操作 |
| --- | --- |
| KEY0 | 增强双目（上电默认，模式1）→整幅视差（模式2）→彩条（模式3）→原始双目（模式0）→增强 |
| KEY1 | 距离系数减小 4/256 |
| KEY2 | 距离系数增大 4/256 |
| KEY3 | 切换正/负视差搜索方向，适应两个摄像头的接线顺序 |

LED[2:0] 显示模式编号，LED3 显示视差方向。模式与校准系数在帧间消隐时锁存，避免在同一显示帧中途切换。按键参数只保存在 RAM，断电后恢复默认。

## 测距标定状态

用户于 2026-10-24 提供镜头中心间距约 **32 mm**，已作为默认基线。`rtl/depth_roi.v` 的 `FOCAL_PX=346` 仍为未标定的初始估计，`scale=256/256` 也不是已验证的标定值。屏幕数值目前只能用于调试；未经实测不能认定达到 0.5～3 m 精度要求。

调试步骤：固定相机，确认左右目同一水平线上的物体高度一致；先用有文字或随机纹理的平面目标置于约 1 m，覆盖白框；在视差模式检查是否形成随目标移动的有效区域。必要时用 KEY3 切换方向。用尺测相机平面到目标的真实距离，再调系数。至少保留 0.5、1、1.5、2、3 m 的实测值验证误差。单一比例校准不能代替双目内外参标定；若垂直错位、镜头畸变或左右曝光时间不一致，需先修正这些问题。
